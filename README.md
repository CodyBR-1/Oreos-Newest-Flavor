Oreo Flavor Recommendation: An end-to-end data pipeline, automated scoring model, and business strategy project to determine a new flavor for Oreo. 


Features: 

ETL Pipeline (Python): Extracts baseline consumer metrics, normalizes variables across a 0-to-1 scale, and applies a weighted composite scoring model.

Visualization (Tableau): A stakeholder-ready dashboard mapping product performance rankings and a risk-versus-reward sentiment scatter plot.

Business Requirements Document: A formal strategy document detailing project scope, target KPIs, demographic goals, and risk mitigations.



Tech Stack: 

Python (Pandas, NumPy): Data extraction, transformation, normalization, and algorithmic scoring.

Tableau Public: Data visualization, filtering, and dashboard design.



What I Learned: 

I learned how to use Python's NumPy library to develop realistic synthetic datasets, allowing me to build and test an ETL pipeline even without access to proprietary company databases.

I discovered the importance of scaling data. By converting metrics to a normalized 0-to-1 scale, I was able to combine fundamentally different data points (like an average rating and social mentions) into a composite score.

Building the interactive Tableau dashboard and writing the BRD taught me how to translate raw terminal outputs into a stakeholder-ready business narrative.
